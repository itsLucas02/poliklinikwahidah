# Poliklinik Wahidah - Clinic Website

A single-page static website for **Poliklinik Wahidah**, a GP clinic in Malaysia.

Live: **https://itslucas02.github.io/poliklinikwahidah/** (GitHub Pages)

## What's inside

- Clinic introduction, services and doctor profiles
- Accepted insurance / panel logos (AIA, Allianz, Great Eastern, Prudential, PMCare, HealthConnect and more)
- One self-contained `index.html` with inline styles (Poppins + Lato, Font Awesome)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server
```

## Note

The page's SEO meta description still contains a `[Your City]` placeholder - replace it with the clinic's real location before going live.
